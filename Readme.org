* tld - a small convenience C library
*tld* is a small C library containing a bunch of convenient function and macros used by Timo Lassmann. It is under active development and therefore not recommended to be used directly in any serious projects. Nevertheless, it may be useful in demonstrating some interesting C techniques. Inspiration for the library comes from many places including:

1) [[https://github.com/EddyRivasLab/easel][easel]] - a C library for biological sequence analysis developed by the [[http://eddylab.org][Eddy/Rivas laboratory]].
2) [[https://github.com/attractivechaos/klib][klib]]
3) [[https://github.com/SasLuca/rayfork][rayfork]] by Sas Luca

An interesting feature is the =galloc= macro, a generic malloc wrapper. It takes a pointer and one or two numbers and allocated either an array or a matrix. For example:

#+begin_src C :eval never
double* arr = NULL;
galloc(&arr, 100)
#+end_src

is equivalent to:

#+begin_src C :eval never
double* arr = NULL;
size_t size = sizeof(double) * 100;
if ((arr = malloc(size) == NULL) {                   
        fprintf(stderr,"malloc of size %d failed", size);
        exit(1);
}
memset(p, 0, size);
#+end_src

For a matrix:

#+begin_src C :eval never 
uint32_t** mat = NULL;
galloc(&mat,100,100);
#+end_src

All memory allocates with =galloc= has to be freed by =gfree= :

#+begin_src C :eval never 
gfree(arr); 
#+end_src

=galloc= support all standard data types (=int=, =float=, =double=) any types found in =stdint.h= (uint8_t etc...). 

*tld* has no dependencies beyond the C standard library, the math library and pthreads. Sequence file IO (FASTA/FASTQ) and the HDF5 wrapper were removed on the =modernisation= branch.

* How to build

#+begin_src bash :eval never 
mkdir build
cd build
cmake ..
make
make test
#+end_src

* Terminal output

Everything goes to stderr, so stdout holds only a program's results. Colour and symbols appear only when stderr is a terminal and =NO_COLOR= is unset. =TLD_VERBOSE= sets how much is shown: =0= errors only, =1= normal (default), =2= also =DEBUG_MSG=.

#+begin_src C :eval never
SECTION_MSG("Aligning %d sequences", n);   /* ── Aligning 40 sequences ────── */
KV_MSG("model", "%s", name);               /*    model     inkling-2-mini     */
OK_MSG("done in %.1f s", t);               /*  ✓ done in 1.9 s                */
DEBUG_MSG("seed %u", seed);                /*  · seed 42   (TLD_VERBOSE=2)    */
for (long i = 0; i < n; i++) { work(i); tld_progress(i + 1, n, "aligning"); }
LOG_MSG(...); WARNING_MSG(...); ERROR_MSG(...);   /* timestamped, as before    */
#+end_src

* tld_ai.h: local models as C functions

=tld_ai.h= is a second single-header library, built on =tld.h=. It calls the LLMs, decision models and embedding models served by the Ollama server on this machine as ordinary C functions: HTTP, JSON, schemas, caching and replay are hidden. It needs nothing beyond libc, libm and pthreads (no libcurl, SQLite or cJSON).

#+begin_src C :eval never
#define TLD_IMPLEMENTATION          /* in one .c file, before any other #include */
#define AI_IMPLEMENTATION
#include "tld_ai.h"

#define TEAM(X) X(bug, "A software defect") X(billing, "Payments and refunds")
AI_CHOICE(team, "Which team should handle this ticket?", TEAM)

int main(void) {
    ai_defaults(AI_CONFIG(.host = "http://localhost:11434", .llm = "inkling-2-mini",
                          .decider = "autotrust-jev", .embedder = "embeddinggemma-2"));
    struct team_answer t = ai_choose(team, "The app crashes on start");
    char *reply = ai_text("Write a one-line apology for: %s", "a crash");
    if (!t.ok || !reply) { fprintf(stderr, "ai: %s\n", ai_error()); return 1; }
    printf("team %d (%.2f): %s\n", t.value, t.confidence, reply);
}
#+end_src

Build with =cc -std=c11 -I. prog.c -lpthread -lm=. Larger examples: =examples/triage.c= (choice, scale, yes/no, struct filling, human review) and =examples/par.c= (parallel calls, embeddings, nearest neighbours). Failures return NULL, -1 or =.ok = 0=; =ai_status()= gives the code (=AI_ENOSERVER=, =AI_ENOMODEL=, ...) and =ai_error()= the message. With no server running every call fails at once with =AI_ENOSERVER=.

** Settings

Every setting is decided on its own, highest first: per-call options (=AI_OPTS(...)=), environment variable, =ai_defaults()=, built-in. The environment is read once, at the first call; a value that does not parse (=TLD_AI_FRESH= takes 1/0, true/false, yes/no, on/off; =TLD_AI_NUM_CTX= and =TLD_AI_TIMEOUT= take positive integers) is ignored with a warning. Each =ai_defaults()= call replaces the previous one; =ai_defaults(NULL)= resets to the built-ins.

| Variable        | Built-in default        | Meaning                                      |
|-----------------+-------------------------+----------------------------------------------|
| TLD_AI_HOST     | http://localhost:11434  | Ollama server (plain http only)              |
| TLD_AI_LLM      | inkling-2-mini:latest   | text model: ai_text, ai_fill                 |
| TLD_AI_DECIDER  | autotrust-jev:latest    | decision model: ai_yesno, ai_choose, ai_rate |
| TLD_AI_EMBEDDER | embeddinggemma-2:latest | embedding model: ai_embed, ai_embed_all      |
| TLD_AI_NUM_CTX  | not sent                | context length for LLM and embedding calls   |
| TLD_AI_TIMEOUT  | 300                     | seconds per request                          |
| TLD_AI_FRESH    | 0                       | 1 = ignore the cache                         |
| TLD_AI_DB       | (no cache)              | cache file (JSON lines); =off= = no cache    |
| TLD_AI_REVIEWS  | ai-reviews              | directory of review files (=ai_review=)      |

With a cache file set (=ai_defaults(AI_CONFIG(.db = "ai.cache"))= or =TLD_AI_DB=), every answered call is appended to it, so a rerun replays finished calls in order and costs nothing. A review is a file =TLD_AI_REVIEWS/<key>.json=; set its ="status"= to ="done"=, fill in ="answer"=, and rerun. Vectors from different embedding models are not comparable; store the embedder's name next to any vectors you save.

** Memory

On a machine that can hold only one model, start Ollama with =OLLAMA_MAX_LOADED_MODELS=1=; the server then swaps models safely between requests.

** Cloud models

Cloud models (those whose =/api/tags= entry has =remote_host=) are reached through the local server. They are opt-in only: the defaults are local, so a prompt leaves the machine only when a cloud model is named in =TLD_AI_LLM=, =TLD_AI_DECIDER=, =TLD_AI_EMBEDDER=, =ai_defaults()= or =.model=. A server that is not signed in answers with an HTTP error, reported as =AI_EHTTP=.

** Tests and the live run

=ctest= runs the tld_ai.h tests against =tests/ai/mock_ollama.py= (started with =uv run python=, or =python3=); they never contact a real server. A run against the real models is manual, for the owner only, with no other model loaded (=ollama ps= shows nothing):

#+begin_src bash :eval never
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release && cmake --build build -j
ollama ps                                   # must list no model
build/tests/ai-hello                         # one call to the default LLM
TLD_AI_DB=build/live.cache build/tests/ai-triage tests/ai/ticket.txt
TLD_AI_DB=build/live.cache build/tests/ai-par 4
ollama ps                                   # models unload after keep_alive (5 min)
#+end_src
